# Verdant — Atelier d'Architecture & Paysage

> 🌐 **Live Demo:** [https://verdant-phi-pink.vercel.app](https://verdant-phi-pink.vercel.app)
Architectural monograph and studio showcase based in Mallorca, featuring real-time solar heliodon simulator, CAD blueprint section X-ray viewer, and material sample archives.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build
```

## Tech Stack
- **React 19** + **TypeScript**
- **Vite 7**
- **Tailwind CSS v4**
- **Interactive Solar Heliodon Canvas Simulator**
- **Architectural Drafting Cursor & CAD Overlays**
- **GSAP & Lenis Smooth Scrolling**
